# بومرنگ — سامانهٔ چت سازمانی

سامانهٔ پیام‌رسان داخلی برای سازمان‌های فارسی‌زبان، با پشتیبانی کامل از راست‌به‌چپ و تقویم شمسی.

## امکانات

- **پیام‌رسانی بلادرنگ** — گفت‌وگوی خصوصی، کانال (یک‌طرفه) و گروه (گفت‌وگویی)، با وضعیت تایپ و نشانگر حضور
- **سه سطح دسترسی** — کارمند، مدیر و ادمین ارشد، با محافظت از مسیرها در سطح روتر
- **پنل مدیر** — تسک، جلسه، اطلاعیه، گزارش عملکرد و مدیریت تیم
- **پنل ادمین** — مدیریت کاربران، فضاهای کاری، فایل‌های سیستم و تنظیمات
- **ارسال فایل** — تصویر و ویدیو با تولید نسخهٔ فشرده و بندانگشتی، به‌همراه پویش ضدبدافزار
- **تم روشن و تیره** — بر پایهٔ توکن‌های معنایی، بدون رنگ سخت‌کدشده
- **بومی‌سازی** — تاریخ شمسی، ارقام فارسی و چیدمان RTL در سراسر برنامه

## پشتهٔ فنی

| لایه | فناوری |
|---|---|
| فرانت‌اند | React 19، TypeScript، TanStack Router / Start / Query، Vite |
| ظاهر | Tailwind CSS v4، Radix UI، توکن‌های oklch |
| بلادرنگ | Socket.IO با آداپتور Redis |
| بک‌اند | Node.js، Express |
| داده | PostgreSQL، Redis |

## اجرا

نیازمندی‌ها: Node.js 20 به بالا، PostgreSQL، Redis

```bash
# بک‌اند
cd backend
cp .env.example .env          # مقادیر را تکمیل کنید
npm install
npm run ensure-db
npm run migrate
npm run seed
npm start

# فرانت‌اند
cd frontend
npm install
npm run dev
```

متغیرهای `DATABASE_URL`، `JWT_SECRET` و `PASSWORD_ENCRYPTION_KEY` الزامی هستند.
کلید رمزنگاری باید دقیقاً ۶۴ کاراکتر هگزادسیمال باشد.

## ساختار

```
backend/          سرور Express، سرویس‌ها، سوکت و مهاجرت‌های پایگاه داده
frontend/         اپلیکیشن TanStack Start
frontend-source/  باندل‌های اولیهٔ رابط کاربری (مرجع طراحی)
```

## تست

```bash
cd backend
npm test     
npm run test:integration  
```
